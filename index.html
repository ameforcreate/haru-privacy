앱의 기록은 사용자의 기기에 보관됩니다.

하루 한 걸음은 별도의 회원가입이나 운영 서버 없이 동작합니다. 앱은 인터넷 권한, 광고 SDK 및 이용 분석 SDK를 사용하지 않으며, 입력한 기록을 운영자에게 전송하지 않습니다.

1. 처리하는 정보와 목적

앱은 사용자가 선택하여 입력하거나 불러온 정보를 기기에서 처리하여 기록·조회·계획·백업 기능을 제공합니다.

  • 일상 기록: 활동, 목표, 일정, 완료 이력, 다이어리, 메모, 스티커 및 선택한 이미지.
  • 생활비 기록: 사용자가 입력한 예산, 지출 및 관련 메모.
  • 앱 설정과 보안 정보: 표시·맞춤 설정, 잠금 설정 및 암호화·인증에 필요한 정보.
  • 선택한 캘린더 정보: 캘린더 이름·계정 식별 정보, 일정 제목·시작 및 종료 시각·종일 여부·일정 식별자. 기기에 있는 Google 캘린더 일정을 앱에서 표시하고 활동과 연결하는 데 사용합니다.

운영자는 앱을 통해 이름, 전화번호, 이메일, 위치, 광고 식별자 또는 기기 내 기록을 서버로 수집하지 않습니다. 사용자가 문의 이메일을 보내는 경우의 정보 처리는 제7항을 따릅니다.

2. 선택 기능과 접근 권한

  • 캘린더 읽기: 사용자가 캘린더 연동을 켜고 권한을 허용한 경우에 사용합니다. Android의 캘린더 제공자를 통해 선택한 캘린더를 읽으며, 앱이 원본 Google 캘린더 일정을 수정하거나 삭제하지 않습니다. 앱 설정에서 연동을 끄거나 Android 설정에서 권한을 철회할 수 있습니다.
  • 생체 인증: 사용자가 지문 등 생체 인증 잠금 해제를 설정한 경우 Android의 인증 기능을 사용합니다. 앱과 운영자는 지문 이미지나 생체 인증 원본 정보를 수집·보관하지 않습니다.
  • 이미지 및 파일 선택: 사용자가 시스템 선택 화면에서 고른 이미지나 백업 파일을 읽거나, 지정한 위치에 백업·이미지를 저장합니다.

선택 기능을 사용하지 않아도 해당 기능을 제외한 앱의 기본 기록 기능을 이용할 수 있습니다.

3. 보관 기간과 보호 조치

앱 내부 기록은 사용자가 삭제하거나 앱 데이터를 삭제할 때까지 기기에 보관됩니다. 앱 제거 시 내부 데이터가 삭제될 수 있습니다. 운영자는 내부 기록의 사본을 보관하지 않으므로 대신 복구해 드릴 수 없습니다.

앱은 내부 기록 암호화, Android Keystore를 이용한 키 보호, 앱 잠금 및 사용자가 선택하는 생체 인증 기능을 제공합니다. 기기 자동 백업과 기기 간 이전에서는 앱 데이터를 제외하도록 설정되어 있습니다.

백업·복원은 사용자가 직접 실행합니다. 복원 전 데이터로 되돌리기 기능을 위해 가장 최근 복원 직전의 암호화된 복구본을 기기 내부에 보관할 수 있습니다.

사용자가 별도로 저장한 암호화 백업이나 내보낸 이미지는 앱 외부에 남습니다. 내보낸 이미지는 일반 이미지 파일이므로 저장 위치와 공유 범위를 직접 관리해 주세요. 백업의 보관 기간과 삭제 여부 역시 사용자가 관리합니다.

4. 제3자 제공 및 외부 서비스

운영자는 앱의 기록을 외부 서버로 전송하거나 제3자에게 제공·판매하지 않습니다. 앱 기록의 서버 처리 위탁, 광고 추적 및 이용 분석을 하지 않습니다.

사용자가 시스템 파일 선택 화면에서 클라우드 저장소를 선택하거나 파일을 다른 서비스로 공유하면 해당 서비스에서 파일이 처리될 수 있으며, 그 서비스의 개인정보처리방침이 적용됩니다. 기기의 Google 계정과 캘린더 동기화는 Android 및 Google 서비스의 설정에 따라 이루어집니다.

이 안내 페이지는 GitHub Pages로 제공됩니다. 앱의 내부 기록과 별개로, 페이지 접속 시 GitHub는 보안 및 서비스 운영을 위해 방문자의 IP 주소를 수집·기록할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요. 이 페이지에는 별도의 분석 도구, 광고, 입력 양식 또는 외부 웹폰트를 넣지 않았습니다.

5. 이용자의 권리와 삭제 방법

  • 열람·수정: 앱의 각 기록 화면에서 자신의 기록을 확인하거나 수정할 수 있습니다.
  • 기록 삭제: 개별 기록의 삭제 기능 또는 설정 → 데이터 및 개인정보 → 기록 전체 삭제를 이용할 수 있습니다. 기록 전체 삭제는 앱 설정, 기본 제공 스티커 및 Google 캘린더 원본을 삭제하지 않습니다.
  • 앱 내부 데이터 전체 삭제: 복구본과 설정을 포함한 내부 데이터를 제거하려면 Android 설정 → 앱 → 하루 한 걸음 → 저장공간에서 데이터 삭제를 이용할 수 있습니다. 메뉴 이름은 기기에 따라 다를 수 있습니다.
  • 외부 파일 삭제: 별도로 저장한 백업·이미지와 클라우드 사본은 해당 저장 위치에서 직접 삭제해야 합니다.
  • 권한 철회: Android 설정 → 앱 → 하루 한 걸음 → 권한에서 캘린더 접근 권한을 변경할 수 있습니다.

운영자는 기기에 저장된 기록에 접근할 수 없습니다. 기록 삭제나 권한 변경에 도움이 필요하면 아래 이메일로 문의해 주세요.

6. 아동의 개인정보

앱은 회원가입이나 서버를 통한 개인정보 수집을 하지 않으며, 아동의 개인정보를 운영자에게 보내도록 요구하지 않습니다. 보호자는 기기의 접근 권한과 파일 공유·백업 설정을 함께 확인하고 관리할 수 있습니다.
